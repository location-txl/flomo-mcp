Let AI read and write your [flomo](https://flomoapp.com) notes directly — no API key required. flomo-mcp is an [MCP](https://modelcontextprotocol.io) server that provides full note and tag read/write access through your locally signed-in flomo desktop client (macOS) to MCP clients such as Claude Desktop, ZCode, and Cursor.

## What is this

flomo has no public API. Instead of reverse-engineering endpoints and hand-crafting signatures, this project connects to the local flomo desktop client via the Chrome DevTools Protocol and calls the app's internal request layer in the page context — tokens, signatures, and routing are all handled by flomo itself:

```
MCP client ──stdio──▶ flomo-mcp ──CDP(127.0.0.1:9222)──▶ flomo desktop app
                                                            │  executed in the flomo page context:
                                                            │  window.__flomoVuexStore._vm.$api.*
                                                            ▼
                                                  https://flomoapp.com/api/v1
                                                  (auth/signing handled by flomo)
```

- **Zero-config auth**: no credentials are stored; the token stays in flomo's localStorage and follows re-logins automatically
- **Update-proof**: API calls reuse the `$api` singleton bundled inside the page, so signatures and headers are generated by the app itself — regular flomo updates don't break compatibility
- **Auto-launch fallback**: each tool call checks the debug port; if flomo isn't running it is launched with `--remote-debugging-port=9222`, and if it's running without the port it is restarted

### What it can do

| You say | Tool invoked |
|---|---|
| "Search my flomo for notes about docker" | `search_memos` |
| "What did I write recently?" | `list_memos` |
| "Save this idea to flomo with the #idea tag" | `create_memo` |
| "Update that note to…" | `get_memo` + `update_memo` |
| "List my tags and pin 'books'" | `list_tags` + `pin_tag` |
| "Rename tag books to reading/books" | `rename_tag` |

All 11 tools (5 read-only / 6 write) with parameters and return shapes are documented in **[TOOLS.md](TOOLS.md)** (Chinese).

## Usage

### Prerequisites

- macOS + a signed-in flomo desktop client (default path `/Applications/flomo.app`)
- Node.js ≥ 20 (uses the native WebSocket; no puppeteer or external browser needed)

### Install

```bash
git clone <repo-url> ~/flomo-mcp
cd ~/flomo-mcp
npm install
npm run build
```

### Register with your MCP client

```json
{
  "mcpServers": {
    "flomo": {
      "command": "node",
      "args": ["~/flomo-mcp/dist/index.js"]
    }
  }
}
```

If flomo is installed elsewhere, specify it via an environment variable:

```json
{
  "mcpServers": {
    "flomo": {
      "command": "node",
      "args": ["~/flomo-mcp/dist/index.js"],
      "env": { "FLOMO_APP_PATH": "/your/path/flomo.app" }
    }
  }
}
```

After restarting the client, ask the AI:

> Use the flomo whoami tool to check the connection

Getting back your account (email masked), note count, and tag count means it works.

### Optional: patch flomo to always start with the debug port

The MCP server has an auto-launch fallback, so patching is optional. Once patched, double-clicking flomo opens it with the debug port — no restart wait on the first tool call:

```bash
npm run patch-flomo          # defaults to /Applications/flomo.app
npm run patch-flomo -- /your/path/flomo.app
```

- Idempotent; the original is backed up as `app.asar.orig`
- **flomo auto-updates overwrite the patch** — just re-run the script afterwards
- To restore the original:

```bash
cp "/Applications/flomo.app/Contents/Resources/app.asar.orig" \
   "/Applications/flomo.app/Contents/Resources/app.asar"
codesign --force --deep --sign - "/Applications/flomo.app"
```

### Troubleshooting

| Symptom | Cause & fix |
|---|---|
| `未登录：请在 flomo 应用中重新登录` (code=-10) | Login expired — open flomo and log in again |
| `编辑冲突` (code=-20) | Note was edited on another device; `get_memo` for the latest content, then update |
| First tool call is slow (~10s) | Auto-launch fallback restarting flomo with the debug port — normal |
| `无法连接 flomo 调试口` | Run `open -a flomo --args --remote-debugging-port=9222` manually; also verify the install path via `FLOMO_APP_PATH` |
| `patch-flomo` fails with `Operation not permitted` | macOS App Management (TCC) blocking an app with quarantine attributes; copy the app without xattrs and patch the copy |
| All tools break after a flomo update | Update overwrote the patched asar → re-run `npm run patch-flomo`; see [AGENT.md](AGENT.md) if it persists |

### Security notes

- The debug port on 9222 is visible to **all local processes** and grants full read/write access to your flomo notes. If this concerns you, switch the injected flag to `--remote-debugging-pipe` (requires matching changes in `src/cdp.ts`)
- This project never writes credentials to disk; `whoami` masks the email address

## Development

### Commands

```bash
npm run build          # compile to dist/ (required after code changes)
node test-e2e.mjs      # end-to-end test of all 11 tools
npm run patch-flomo    # ASAR patch (optional)
```

### Testing notes

The e2e test runs against your **real flomo account**: write operations form a create→update→rename→pin→delete loop with automatic cleanup — do not remove the cleanup logic. Prerequisites: flomo signed in and the debug port reachable; `export FLOMO_APP_PATH=...` first if flomo isn't at the default path.

### Source layout

```
src/
├── index.ts   # stdio MCP server entry + 11 tool registrations
├── cdp.ts     # CDP client: probe/auto-launch flomo, evaluate in page context
├── api.ts     # call layer reusing the in-page $api + flomo time/timezone helpers
└── tools.ts   # tool implementations and parameter schemas
scripts/
└── patch-flomo.mjs  # ASAR patch (idempotent)
```
