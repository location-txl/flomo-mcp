04 / 现在，连起来

简单配置，
开始新的对话。

准备好已登录的 flomo 桌面端，将配置加入支持 MCP 的客户端，再验证连接。

开始之前

✓ macOS

✓ Node.js ≥ 22.4

✓已登录的 flomo 桌面客户端

阅读完整安装指南 →
1

添加 MCP 配置

把下面的配置添加到客户端的 MCP 配置中。客户端启动服务时，npx 会下载并运行软件包。

mcp-config.json
{
  "mcpServers": {
    "flomo": {
      "command": "npx",
      "args": ["-y", "@location-txl/flomo-mcp"]
    }
  }
}

默认路径为 /Applications/flomo.app。如安装在其他位置，请在服务配置的 env 中设置 FLOMO_APP_PATH。

2

重启 MCP 客户端

确认 flomo 已登录。首次调用可能会启动或重启 flomo，以打开调试端口；请先保存正在编辑的内容。

3

和你的笔记打个招呼

用 flomo 的 whoami 看看连上了吗。

返回账号标识、笔记与标签总数，即连接成功。以邮箱作为账号标识时，邮箱会脱敏。

首次使用无需修改 flomo 安装文件。可选的调试口注入，请先阅读 README 中的说明。

使用之前，了解这些

你可能还想知道。

开源，也把边界说清楚。

这是 flomo 官方出品的吗？

不是。flomo-mcp 是 location-txl 维护的独立开源项目，采用 MIT 许可。本网站是 flomo-mcp 项目网站，不是 flomo 产品官网，也不代表 flomo 官方。请遵守 flomo 服务条款使用。

我需要注意哪些安全问题？

服务复用 flomo 的登录状态，自身不保存凭证。但 127.0.0.1:9222 调试端口会赋予本机进程笔记读写能力，请勿将它暴露或转发到不可信网络。连接的 AI 客户端会接收工具返回内容，请检查其隐私设置，并谨慎确认写入操作。

支持 Windows、手机或纯网页版吗？

当前实现要求 macOS，以及与 MCP 服务运行在同一台电脑上、已登录的 flomo 桌面客户端。它是本地 stdio 服务，不是托管的 HTTP 接口，目前不支持 Windows、仅手机或纯网页版环境。

搜索是无限量的语义搜索吗？

不是。search_memos 拉取笔记后，在本地按关键词匹配正文与标签。扫描有 40 页保护上限（最多 4,000 条记录）；complete: false 表示结果可能不完整。AI 客户端可以理解返回的笔记，但工具本身不是语义搜索引擎。

flomo 更新后还能正常使用吗？

本项目依赖桌面客户端内部结构，因此无法保证所有更新都兼容。更新可能覆盖可选注入，也可能改变内部接口。遇到问题时请先查看 README 排查步骤，再到 GitHub 提交可复现的问题。
